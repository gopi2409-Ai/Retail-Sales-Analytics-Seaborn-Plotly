# Retail Sales Analytics Dashboard

## About the Project
This project uses Python, Pandas, Seaborn, and Plotly to analyze retail sales data and visualize revenue, expenses, profit, and orders.

## Features
- Analyze sales data using Pandas.
- Calculate revenue, expenses, profit, and orders.
- Visualize revenue distribution using Seaborn.
- Compare revenue and expenses.
- Create interactive revenue and profit charts using Plotly.
- Export charts and analyzed data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
